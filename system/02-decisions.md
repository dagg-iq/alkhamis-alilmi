# القرارات التقنية

الحالة: ✅ معتمد | 🟡 مقترح ينتظر موافقة | ❌ مرفوض

## 1. إطار عمل التطبيق — 🟡 مقترح: React Native + Expo (TypeScript)
| الخيار | الحكم |
|---|---|
| Kotlin أصلي | أداء ممتاز لكن أندرويد فقط، وكود منفصل عن لوحة التحكم، وتطوير أبطأ |
| HTML/CSS/JS داخل WebView | ❌ ضعيف: الكاميرا والإشعارات والدردشة اللحظية وفتح الملفات دون إنترنت كلها سيئة، والإحساس "ليس تطبيقاً حقيقياً" |
| Flutter | ممتاز، لكن لغة Dart مختلفة عن لوحة التحكم (React) |
| **React Native + Expo** | ✅ تطبيق أصلي حقيقي، أندرويد + آيفون من نفس الكود، نفس اللغة (TypeScript) ونفس الأسلوب (React) مع لوحة التحكم ← مشاركة الأنواع والمنطق (مثل حاسبة الإعفاء) بين الاثنين، وبناء APK سهل عبر EAS |

## 2. لوحة التحكم — 🟡 مقترح: React + Vite + TypeScript ← Netlify
- موقع منفصل للأدمن فقط، دخول محمي بصلاحية admin من قاعدة البيانات.

## 3. الخلفية (Backend) — 🟡 مقترح: Supabase
- **قاعدة البيانات** Postgres + **المصادقة** + **Realtime** للدردشة + **Edge Functions** للذكاء الاصطناعي + **pgvector** للبحث في المنهج.
- **حماية الصلاحيات** عبر Row Level Security (الطالب لا يستطيع تعديل المحتوى حتى لو عبث بالتطبيق).

### هل تكفي الخطة المجانية؟
| المورد | المجاني | تقديرنا |
|---|---|---|
| قاعدة البيانات | 500 MB | ✅ يكفي بسهولة (نصوص، درجات، رسائل) |
| تخزين الملفات | 1 GB | ❌ لا يكفي للملازم (ملزمة واحدة قد تكون 20–80 MB) |
| نقل البيانات (Egress) | 5 GB/شهر | ❌ 40 طالباً يحمّلون ملازم ← يُستهلك بسرعة |
| المستخدمون النشطون | 50,000 | ✅ |
| التوقف | يتوقف المشروع بعد 7 أيام بلا نشاط | ⚠️ مشكلة في العطل |

**الحل المقترح:** Supabase المجاني للبيانات + **Cloudflare R2** للملفات الكبيرة
(10 GB مجاناً، وتحميل بلا رسوم نقل). الفيديوهات روابط يوتيوب فقط (لا تخزين).
الصور تُضغط داخل التطبيق قبل الرفع. لاحقاً عند الحاجة: Supabase Pro (25$/شهر).

## 4. المساعد الذكي — 🟡 مقترح
- Claude API عبر Supabase Edge Function (المفتاح لا يوضع أبداً داخل التطبيق).
- RAG: تقطيع الملازم والكتب إلى نصوص ← تخزينها في pgvector ← المساعد يجيب من المنهج ويذكر المصدر (المادة/الفصل/الصفحة).
- حد يومي للرسائل لكل طالب للتحكم بالتكلفة.
- ملاحظة صريحة: لا يوجد ذكاء اصطناعي "بدون أي أخطاء"؛ الاعتماد على المنهج وذكر المصدر يقلل الأخطاء كثيراً.

## 5. تصوير الأسئلة ← PDF/نص — 🟡 مقترح
- ماسح المستندات (قص تلقائي + تصحيح الميلان + تحسين التباين) عبر Google ML Kit Document Scanner.
- استخراج النص العربي والمعادلات بنموذج رؤية (Claude Vision) ← نص منسق + معادلات LaTeX.
- الأدمن يراجع النص قبل النشر.
