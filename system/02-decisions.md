# القرارات التقنية

الحالة: ✅ معتمد | 🟡 مقترح ينتظر موافقة | ❌ مرفوض

## نطاق المشروع ✅
- البداية: **صف/مدرسة واحدة**، ثم التوسع لبقية الصفوف إذا نجح التطبيق. التصميم يدعم التوسع من البداية (جدول schools/classes).
- **أندرويد أولاً** (APK). الكود يدعم آيفون لاحقاً دون إعادة كتابة.
- **كل شيء مجاني** قدر الإمكان.
- **تقسيم العمل**: المساعد يكتب كل الكود. صاحب المشروع يخطط ويفحص ويجرب، وينشئ الحسابات والمفاتيح (Supabase, Google AI, Cloudflare, Netlify) ويربطها.
- **التنفيذ بخطوات** حسب `TASKS.md`، وليس عشوائياً.
- **الأدمن يرى كل شيء**: كل الطلاب المسجلين، درجاتهم، نشاطهم.
- **التطبيق مضبوط**: كل طالب معرَّف بحسابه، لا يدخل أحد دون موافقة الأدمن.

## 1. إطار عمل التطبيق ✅ React Native + Expo (TypeScript)
السبب: سريع في التطوير، تطبيق أصلي حقيقي، واجهة جميلة وسهلة، نفس لغة لوحة التحكم.
| الخيار | الحكم |
|---|---|
| Kotlin أصلي | ❌ أبطأ في التطوير، كود منفصل عن لوحة التحكم |
| HTML/CSS/JS داخل WebView | ❌ الكاميرا والإشعارات والدردشة وعدم الاتصال ضعيفة |
| Flutter | ❌ لغة Dart مختلفة عن لوحة التحكم |
| **React Native + Expo** | ✅ |

**أدوات الواجهة:**
- **Expo Router**: التنقل بين الشاشات. **Expo SDK 57**.
- ~~NativeWind~~ ← **مكونات خاصة بـ StyleSheet** (`apps/mobile/src/components/ui.tsx`) بألوان الهوية من `@saey/shared`. السبب: أقل اعتماديات وأقل مشاكل بناء، وتحكم كامل بالتصميم.
- **RTL مفروض** على كامل التطبيق + خط عربي واضح (مثل IBM Plex Sans Arabic أو Cairo).
- **مبدأ التصميم**: الطالب لا يحتاج أن يفكر — أزرار كبيرة، أيقونات واضحة، 3 نقرات كحد أقصى للوصول لأي شيء، وضع ليلي.
- **البناء**: EAS Build ← ملف APK.

## 2. لوحة التحكم ✅ React + Vite + TypeScript ← Netlify
- موقع للأدمن فقط، دخول محمي بصلاحية admin من قاعدة البيانات.

## 3. الخلفية ✅ Supabase (الخطة المجانية) + Cloudflare R2 للملفات
- Postgres + المصادقة + Realtime (الدردشة) + Edge Functions + pgvector.
- الصلاحيات عبر Row Level Security.
- **الملفات الكبيرة** (الملازم PDF): Cloudflare R2 (10GB مجاناً، تحميل بلا رسوم نقل).
- **الصور** (صور شخصية، صور الدردشة): تُضغط في التطبيق قبل الرفع.
- **الفيديوهات**: روابط يوتيوب فقط.
- ⚠️ مشروع Supabase المجاني يتوقف بعد 7 أيام بلا نشاط ← مهمة مجدولة بسيطة (ping) تبقيه نشطاً.

## 4. المساعد الذكي ✅ Google Gemini API (الطبقة المجانية)
- النموذج: `gemini-2.5-flash` للأسئلة، و`gemini-2.5-flash-lite` للمهام الخفيفة (حدوده المجانية أعلى).
- الاستدعاء عبر Supabase Edge Function — المفتاح لا يوضع أبداً في التطبيق أو المستودع.
- RAG من المنهج (pgvector) + ذكر المصدر.
- **حد يومي لكل طالب** (قابل للتعديل من لوحة التحكم) + عداد استهلاك عام يظهر للأدمن.
- عند الوصول للحد: رسالة لطيفة «انتهى رصيدك اليوم، يتجدد غداً».

### ⚠️ حقائق مهمة عن Gemini (تم التحقق أكتوبر 2026)
1. **اشتراك Google AI Pro لا يعطي أي رصيد للـ API.** الاشتراك للتطبيق والمحادثة فقط؛ الـ API له طبقة مجانية منفصلة متاحة لأي حساب.
2. **الحدود المجانية لكل مشروع (Project) وليس لكل مفتاح**، وقد خفّضتها Google في ديسمبر 2025 (تقريباً 250–500 طلب/يوم لـ Flash، وأحياناً أقل).
3. **استخدام عدة حسابات لتجاوز الحدود مخالف لشروط Google** وقد يؤدي لحظر الحسابات (ومنها حساباتكم الشخصية). ❌ لن نعتمد عليه.
4. بيانات الطبقة المجانية قد تستخدمها Google لتحسين نماذجها ← لا نرسل بيانات شخصية للطلاب (الأسماء، الدرجات) للنموذج.
5. **الخطة البديلة** إذا كبر الاستخدام: الدفع حسب الاستخدام لـ Flash-Lite رخيص جداً (غالباً أقل من بضعة دولارات شهرياً لصف واحد).

**توفير الطلبات:** تخزين إجابات الأسئلة المتكررة، اختبارات ذاتية مولّدة مسبقاً وتُعاد، Flash-Lite للمهام البسيطة.

## 5. تصوير الأسئلة ← PDF/نص ✅
- الإصدار الأول: كاميرا expo-image-picker مع القص + ضغط بدقة عالية. (ML Kit Document Scanner مؤجل لأنه يحتاج مكتبة أصلية إضافية.)
- PDF من الصور يُنشأ في الخادم بـ pdf-lib، والنص يُستخرج بـ Gemini.
- استخراج النص العربي والمعادلات بـ Gemini Vision ← نص + LaTeX.
- الأدمن يراجع قبل النشر.

## 9. الهوية والتصميم ✅ (الاتجاه) — 🟡 (الاسم والألوان النهائية)
- **الخط: ثمانية (Thmanyah)** — Sans للواجهة، Serif Display للعناوين الكبيرة، Serif Text للقراءة الطويلة. الملفات في `assets/fonts/thmanyah/`.
- **الأسلوب**: مثل تطبيق ثمانية + إتقان التطبيقات العالمية (تلجرام، ديسكورد). بعيد تماماً عن «شكل تصاميم الذكاء الاصطناعي»: لا تدرجات لونية مبالغ فيها، لا ظلال كثيرة، لا أيقونات تعبيرية عشوائية. طباعة قوية، مساحات بيضاء، لون مميز واحد.
- **الثيم**: فاتح افتراضياً + غامق قابل للتبديل (ويتبع إعداد الهاتف تلقائياً).
- **اسم التطبيق ✅ «سعي»** — التفاصيل الكاملة للهوية في `05-brand.md`.

## 10. قرارات التنفيذ ✅ (الجلسة ١)
- **Monorepo** بـ npm workspaces: `apps/mobile` و `apps/admin` و `packages/shared`.
- **`packages/shared`**: منطق الدرجات والإعفاء + الأنواع + ألوان الهوية + تنسيق الأرقام العربية — مشترك بين التطبيق ولوحة التحكم، ومغطى باختبارات.
- **لوحة التحكم**: React 19 + Vite 7 + react-router 7، CSS خاص بمتغيرات الهوية (فاتح/غامق تلقائي).
- **قراءة الملازم**: تُحمّل وتُفتح بقارئ PDF في الهاتف (وتبقى محفوظة للقراءة دون إنترنت).
- **المعادلات**: KaTeX (داخل WebView في التطبيق، ومباشرة في لوحة التحكم).
- **فهرسة الملازم للمساعد**: Gemini File API + نسخ ١٠ صفحات في كل استدعاء + embeddings (768 بُعداً) في pgvector.
- **الإشعارات**: جدول `notifications` + Database Webhooks ← دالة `push` ← Expo Push.
- **سجل العمليات**: مشغّل `audit()` يسجل عمليات الأدمن والمشرفين تلقائياً.
