# خريطة الشاشات

## تطبيق الهاتف (`apps/mobile`)

### قبل الدخول
| الشاشة | المسار | المحتوى |
|---|---|---|
| الترحيب | `/(auth)/welcome` | الشعار، «اسعَ تُعفَ.»، زر «الدخول بحساب Google» |
| إكمال البيانات | `/(auth)/onboarding` | الاسم الثلاثي، الصورة، اختيار الشعبة |
| بانتظار الموافقة | `/(auth)/pending` | رسالة + زر تحديث + تسجيل خروج (وتظهر أيضاً للمرفوض/المحظور) |

### الأقسام الرئيسية (شريط سفلي)
| القسم | المسار | المحتوى |
|---|---|---|
| **الرئيسية** | `/(tabs)/index` | التحية، بطاقة طريق الإعفاء، الامتحان القادم + العدّاد، مهام اليوم، آخر خبر، المواد |
| **المواد** | `/(tabs)/subjects` | قائمة المواد الثمانية مع نسبة التقدم |
| **الدرجات** | `/(tabs)/grades` | المعدل، الإعفاء الفردي والعام، جدول المواد، «تحتاج»، زر إضافة درجة |
| **الدردشة** | `/(tabs)/chat` | قائمة المحادثات (المدرسة، الشعبة، المجموعات، الخاصة) + غير المقروء |
| **المزيد** | `/(tabs)/more` | الملف الشخصي، المنظِّم، الأخبار، المساعد الذكي، مؤقت الدراسة، تصوير الأسئلة (للأدمن/المشرف)، الإعدادات |

### شاشات داخلية
| الشاشة | المسار | المحتوى |
|---|---|---|
| المادة | `/subject/[id]` | تبويبات: المحاضرات / الملازم / الأسئلة المتوقعة / امتحاناتنا. الأجزاء (للعربي) ثم الفصول |
| المحاضرة | `/lecture/[id]` | مشغل يوتيوب، علامة «شاهدت»، المحاضرة التالية |
| الملف | `/document/[id]` | «فتح» (يحمّل بالخلفية مع النسبة ثم يفتح) + «تحميل للقراءة بلا إنترنت» + الفصول والمواضيع |
| الأسئلة | `/questions/[id]` | نص الأسئلة (مع المعادلات) أو PDF |
| تفاصيل درجة المادة | `/grades/[subjectId]` | الأشهر الأربعة + نصف السنة، السعي، المطلوب لكل هدف |
| إضافة/تعديل درجة | `/grades/edit` | المادة، الامتحان، الدرجة |
| المنظِّم | `/planner` | الواجبات والتحضيرات والامتحانات، تبويب اليوم/القادم/المنجز |
| مهمة جديدة | `/planner/new` | النوع، المادة، العنوان، الموعد، التذكير، (للمشرف: للشعبة/للجميع) |
| الأخبار | `/news` و `/news/[id]` | الأخبار المثبتة أولاً |
| المحادثة | `/chat/[id]` | الرسائل لحظياً، رد، تاغ @، صورة (مضغوطة)، ملف PDF، إرفاق من المنهج، تفاعل |
| رسالة جديدة | `/chat/new` | اختيار طالب لمحادثة خاصة |
| المساعد الذكي | `/ai` و `/ai/[id]` | «ناقش مادة معيّنة»، محادثات، الرصيد اليومي (الخاص أو العام)، مرفقات (صور/PDF)، اقتراحات تُكتب في الصندوق، شرح فصل طويل على أقسام + PDF مدموج، المصادر تحت كل جواب |
| اختبار ذاتي | `/quiz/[chapterId]` | أسئلة اختيار من متعدد مع الشرح |
| مؤقت الدراسة | `/timer` | بومودورو ٢٥/٥، اختيار المادة، إحصائيات الأسبوع |
| تصوير الأسئلة | `/scan` | الكاميرا ← قص وتحسين ← استخراج النص ← مسودة للمراجعة |
| الملف الشخصي | `/profile/[id]` | الصورة، الاسم، الشعبة، شارة التوثيق، زر مراسلة؛ ملف المطوّر يعرض بطاقة المطور |
| الإعدادات | `/settings` | الثيم (فاتح/غامق/تلقائي)، الإشعارات، تعديل الملف، خروج |

## لوحة التحكم (`apps/admin`) — للأدمن والمشرفين
| الصفحة | المحتوى |
|---|---|
| الدخول | Google — يُرفض أي حساب ليس admin/moderator |
| نظرة عامة | عدد الطلاب، طلبات الانتظار، استهلاك الذكاء الاصطناعي اليوم، آخر النشاطات |
| الطلاب | طلبات التسجيل (قبول/رفض)، كل الطلاب، تغيير الدور والشعبة، التوثيق، الحظر، عرض درجات أي طالب، حصة أسئلة المساعد لكل طالب |
| الشعب | إضافة/تعديل/حذف |
| المواد والفصول | المواد ← الأجزاء ← الفصول (ترتيب بالسحب لاحقاً) |
| الأساتذة | إضافة/تعديل |
| المحاضرات | لصق رابط يوتيوب ← يُملأ الباقي، اختيار الفصل والأستاذ |
| الملازم | رفع PDF إلى التخزين، ربطه بالمادة/الفصل |
| الأسئلة | المتوقعة وامتحاناتنا: إنشاء، مراجعة المسودات المصورة، نشر |
| الأخبار | نشر خبر + إشعار فوري |
| المهام العامة | واجبات وامتحانات للشعبة أو للجميع |
| الدردشة | المحادثات وحذف الرسائل المخالفة، «مسح الرسائل» لمحادثة، «مسح كل الدردشات» (بتأكيد مكتوب «حذف») |
| الإعدادات | أرقام الإعفاء، فتح/إغلاق التسجيل، الرسائل الخاصة، حدود المقرر للمساعد لكل مادة |
| الاستخدام | حصص Gemini لكل مفتاح ونموذج، آخر تجدد والتجدد القادم (١٠ صباحاً بغداد صيفاً)، النماذج المتاحة الآن، تشغيل المساعد وحده اليومي العام، استخدام الطلاب |
| سجل العمليات | كل ما فعله الأدمن والمشرفون |
