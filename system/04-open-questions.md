# أسئلة مفتوحة لصاحب المشروع

> عند الإجابة: انقل الجواب إلى الملف المناسب واحذف السؤال من هنا.

1. **طريقة الدخول**: أيها تفضل؟
   - (أ) حساب Google بضغطة واحدة ← ثم إكمال البيانات ← موافقة الأدمن *(مقترح: الأسهل والمجاني)*
   - (ب) اسم مستخدم + كلمة سر يصنعها الأدمن لكل طالب
   - (ج) رقم الهاتف برسالة SMS ← ❌ مكلف
2. **المدرسة**: اسم المدرسة، وكم شعبة للخامس العلمي (أ، ب، ج…)؟
3. **الهوية**: اسم التطبيق الظاهر للطلاب، والألوان المفضلة؟
4. **الملازم**: عندما تجمعها، أي أساتذة/ملازم لكل مادة؟ (يمكن تأجيله لمرحلة المحتوى)
