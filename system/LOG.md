- **العارض**: كان يبقي كل الصفحات المرسومة في الذاكرة (كتاب ٣٠٠ صفحة يُسقط التطبيق) ← يحرّر البعيدة (اختُبر ١٢٠ صفحة: ٥ صفحات في الذاكرة). قائمة «خيارات» بدل ٦ أزرار.
- **الفهرسة**: مهلة زمنية داخل الدالة (حد Supabase ~١٥٠ ث) تحفظ الصفحات المقروءة وتكمل الباقي لاحقاً.
- **بلا إنترنت (مهم)**: بعد ساعة من آخر اتصال يرسل supabase-js مفتاح anon بدل رمز الطالب فلم يُقرأ أي محفوظ، وكانت الجلسة الفارغة تمحو الجلسة المخزنة ← المحفوظ صار باسم الطالب لا برمز الدخول، ويُقرأ رغم ذلك ولا يُحفظ رد anon، وتُتجاهل الجلسة الفارغة إلا عند خروج صريح. الرئيسية كانت تفرغ بلا إنترنت (فلتر وقت بالملي ثانية لا يطابق المحفوظ) ← فلاتر بحسب اليوم وكل جزء مستقل. فهرس المحفوظ كان يضيع مفاتيح عند الطلبات المتزامنة ← كتابة بالتتابع، والمسح يشمل كل المفاتيح. المهلة ١٥ ث صارت فقط عند وجود محفوظ. دخول حساب آخر بعد خروج بانتهاء الجلسة يمسح بيانات السابق (الهدف لا يُنسخ لحساب آخر). اختبار `apps/mobile/e2e/offline-test.cjs`.
- **تحميل الملازم**: زرّا «تحميل» و«فتح» معاً كانا يحفظان ملفاً ناقصاً للأبد ← تحميل واحد لكل ملف.
- **التحديث**: تحميل انقطع كان يُعدّ جاهزاً فيفشل التثبيت كل مرة ← ملف مؤقت `.part` ثم نقل مع فحص الحجم. «إلغاء» كان يظهر كخطأ ← أُصلح. شاشة «عن التطبيق» بعد فشل التحميل صار فيها زر إعادة المحاولة.
- **الجداول**: حصة فارغة كانت تُكرر الحصة التالية في الجدول والطباعة، و«+ حصة» كانت تعيد ترقيم الحصص فتنتقل المواد ← أُصلح.
- **لوحة التحكم**: HTML القادم من الذكاء الاصطناعي يُنقّى قبل عرضه (كان يمكن تمرير سكربت بـ `<svg/onload>`) — اختُبر. أزرار الصور معطلة أثناء التحويل (كان يمكن نشر PDF لا يطابق الصور).
