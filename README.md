# سعي — اسعَ تُعفَ.

تطبيق طلاب **الخامس الإعدادي العلمي** — إعدادية الشهاب للبنين.

المحاضرات، الملازم، الأسئلة المتوقعة، أسئلة امتحانات المدرسة، سجل درجات يحسب الإعفاء،
دردشة، أخبار، مساعد ذكي للمنهج، ومنظِّم للدراسة — في مكان واحد.

| | |
|---|---|
| 📱 `apps/mobile` | تطبيق أندرويد (Expo / React Native) |
| 🖥️ `apps/admin` | لوحة التحكم (React + Vite → Netlify) |
| 🧮 `packages/shared` | حساب السعي والإعفاء + الهوية |
| 🗄️ `supabase/` | قاعدة البيانات والصلاحيات ودوال الخادم |
| 🧭 `system/` | **التخطيط والقرارات ودليل الإعداد** — ابدأ من هنا |
